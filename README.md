# 🌐 Friendo

A modern social media platform built with **React**, **Tailwind CSS**, and **JavaScript** that enables users to connect, share updates, communicate with friends, and manage their social presence through a clean and responsive user interface.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/gauravkumar2005/Friendo.git
```

### 2. Navigate to the project directory

```bash
cd friendo
```

### 3. Install dependencies

```bash
npm install
```

### 4. Install required packages

```bash
npm install react-router-dom lucide-react
```

### 5. Run the development server

```bash
npm run dev
```

Open http://localhost:5173 in your browser to view the application.
